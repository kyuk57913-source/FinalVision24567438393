Vision app — файлыг бүрэн шинэчлэх багц

Энэ багцад Vision app-ийн үндсэн файл болон шаардлагатай зураг, загварын файл, программын хэсгүүд орсон. P&L картын графикийн шугамыг картын дэвсгэртэйгээ тод ялгарахаар зассан. Цайвар дэвсгэр дээр бараан шугам, бараан дэвсгэр дээр цайвар шугам автоматаар сонгогдоно. Бусад байрлал, товчлуур, үйлдлийг өөрчлөөгүй.

Хэрэглэхдээ ZIP-ийг задлаад доторх бүх файлыг GitHub repository-ийн үндсэн хэсэгт оруулж, хуучин файлуудыг солино. ZIP файлыг дангаар нь оруулж болохгүй. Дараа нь GitHub-ийн тохиргооноос Pages-ийг main салбарын үндсэн хавтаснаас нийтэлнэ.
